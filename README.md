# ScholarshipReady

A free, trust-first web platform that helps students find scholarships they're eligible for, check their documents against each scheme's requirements, and prepare a ready-to-submit application pack — without OTP sharing or cyber cafés.

## Status
🚧 In development — dashboard complete (filters + seed data). Detail page and document readiness checker coming next.

## Tech
- HTML, CSS, vanilla JavaScript (no framework yet)

Open `index.html` in a browser, or:
